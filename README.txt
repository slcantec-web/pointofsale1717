Products tab UI fix (mobile)
============================

What you get
------------
Products tab has a clear sub-menu:
  List | Add item | Stock | Categories

- Only one section on screen at a time (much clearer on phone)
- Stock has big toggle: "Stock in (receive)" vs "Adjust (+ / −)"
- Stock Adjust is easy to find under the Stock tab
- Colored left borders so sections don't look the same
- Product row "STOCK" button opens Stock panel with that item selected

No D1 or worker changes for this UI-only fix.
